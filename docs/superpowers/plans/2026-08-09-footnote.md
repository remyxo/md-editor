# 脚注（Footnote）功能实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 md-editor 增加脚注支持：正文 `[^id]` 显示为上标标记，文末有可视化定义区，任意中英文名标记，MD↔HTML 100% 往返不丢失。

**Architecture:** 沿用现有"占位符预处理"模式（与任务列表/数学公式/下标同构）解决 `QTextDocument`/md4c 不识别 `[^id]` 的问题；在 `editor.js` 内自建三个 TipTap 节点（footnoteReference / footnoteContainer / footnoteDef），不引入 npm 依赖；C++ 工具栏/菜单/图标按既有 6 步流程接入。

**Tech Stack:** Qt6 + QTextDocument(md4c)（MD↔HTML 转换）、TipTap/ProseMirror（WYSIWYG 节点）、QSS/SVG（工具栏图标）、QTest（C++ 单元测试）。

> 设计依据：`docs/superpowers/specs/2026-08-09-footnote-design.md`（已确认）。

## 设计澄清（实现层面，对 spec 的精确化）

1. **footnoteDef 的标记与内容分离**：spec 3.3 要求 renderHTML 产出 `<span class="footnote-marker">` 并"内容取 marker 之后部分"。ProseMirror 解析时，marker span 与正文 inline 内容是同一 div 的兄弟节点，直接解析会让 marker 文本污染 def 内容。**解决办法**：renderHTML 把正文包进 `<span class="footnote-content">`，`parseHTML` 用 `getContentElement` 返回 `.footnote-content`，fromHtml 用正则取该 span 内 HTML。marker span 设 `contenteditable="false"` 防止误编辑。最终 HTML 契约统一为：
   `<div data-type="footnoteDef" data-id="{id}"><span class="footnote-marker" contenteditable="false">{id}</span><span class="footnote-content">{inline}</span></div>`，toHtml 构造的 def HTML 也用同一结构（保证往返一致）。

2. **行内代码保护**：`[^x]` 出现在反引号行内代码内时不转换。toHtml 的 `extractFootnoteRefs` 先把 `` `...` `` 片段暂存为 `\x01CODEn\x01` 哨兵，转换引用后再还原。

```cpp
// 提取脚注引用 [^id] → ZZFR 占位符（后处理还原为 <sup data-type="footnoteRef">）。
// 先保护行内代码 `...`（其内的 [^x] 原样保留），再转换引用，最后还原代码。
static QString extractFootnoteRefs(QString line, QStringList &refs)
{
    // 1) 暂存行内代码片段（含 [^x] 的反引号内容不转换）
    QStringList codes;
    QRegularExpression codeSpanRe("`([^`]+)`");
    int off = 0;
    while (true) {
        auto m = codeSpanRe.match(line, off);
        if (!m.hasMatch()) break;
        codes << m.captured(0);
        QString cph = "\x01CODE" + QString::number(codes.size() - 1) + "\x01";
        line.replace(m.capturedStart(), m.capturedLength(), cph);
        off = m.capturedStart() + cph.length();
    }
    // 2) 转换脚注引用 [^id]
    QRegularExpression refRe("\\[\\^([^\\]]+?)\\]");
    off = 0;
    while (true) {
        auto m = refRe.match(line, off);
        if (!m.hasMatch()) break;
        QString id = m.captured(1).trimmed();
        refs << ("<sup data-type=\"footnoteRef\" data-id=\"" + id + "\">"
                 + id + "</sup>");
        QString ph = "ZZFR" + QString::number(refs.size() - 1) + "ZZ";
        line.replace(m.capturedStart(), m.capturedLength(), ph);
        off = m.capturedStart() + ph.length();
    }
    // 3) 还原行内代码
    for (int i = 0; i < codes.size(); ++i)
        line.replace("\x01CODE" + QString::number(i) + "\x01", codes[i]);
    return line;
}

// 脚注定义内容（MD 行内）→ footnoteDef 契约 HTML（marker + footnote-content 包裹）。
// 内容借嵌套 QTextDocument 转 inline HTML（保留粗体/斜体/链接等），仅取首段 inline。
static QString buildFootnoteDefHtml(const QString &id, const QString &contentMd,
                                    QStringList &subContents)
{
    QTextDocument d;
    d.setMarkdown(extractSubscripts(contentMd, subContents));
    QString h = d.toHtml();
    auto bm = QRegularExpression("<body[^>]*>(.*)</body>",
        QRegularExpression::DotMatchesEverythingOption).match(h);
    QString inner = bm.hasMatch() ? bm.captured(1).trimmed() : QString();
    // 去掉外层 <p></p>，仅保留 inline
    inner.remove(QRegularExpression("^\\s*<p[^>]*>"));
    inner.remove(QRegularExpression("</p>\\s*$"));
    return "<div data-type=\"footnoteDef\" data-id=\"" + id + "\">"
         + "<span class=\"footnote-marker\">" + id + "</span>"
         + "<span class=\"footnote-content\">" + inner + "</span></div>";
}
```

```cpp
// fromHtml 方向：从 <div 开标签位置平衡扫描，返回配对 </div> 的起始位置；失败返回 -1
static int findMatchingDivClose(const QString &s, int openTagStart)
{
    static const QRegularExpression divTagRe("<(/?)div\\b[^>]*>");
    int depth = 0;
    int pos = openTagStart;
    while (true) {
        auto m = divTagRe.match(s, pos);
        if (!m.hasMatch()) return -1;
        if (m.captured(1).isEmpty()) ++depth;    // <div ...>
        else if (--depth == 0) return m.capturedStart();
        pos = m.capturedEnd();
    }
}
```

```javascript
// - id 为字面标记文本（"1" / "注1" / "附录A"）

function buildFootnoteReference() {
    return TipTapNode.create({
        name: 'footnoteReference',
        group: 'inline',
        inline: true,
        atom: true,
        selectable: true,
        addAttributes: function() {
            return {
                id: { default: '' }
            };
        },
        parseHTML: function() {
            return [{
                tag: 'sup[data-type=footnoteRef]',
                getAttrs: function(el) {
                    return { id: el.getAttribute('data-id') || '' };
                }
            }];
        },
        renderHTML: function(ref) {
            var id = ref.node.attrs.id;
            return ['sup', { 'data-type': 'footnoteRef', 'data-id': id }, id];
        },
        addNodeView: function() {
            return function(ref) {
                var node = ref.node;
                var dom = document.createElement('sup');
                dom.setAttribute('data-type', 'footnoteRef');
                function render() {
                    dom.setAttribute('data-id', node.attrs.id);
                    dom.textContent = node.attrs.id;
                }
                render();
                dom.title = '双击修改脚注标记';
                dom.addEventListener('dblclick', function(e) {
                    e.preventDefault();
                    e.stopPropagation();
                    var cur = node.attrs.id;
                    var v = prompt('脚注标记:', cur);
                    if (v != null) {
                        v = v.trim();
                        // 禁止空串与脚注语法字符
                        if (v && v !== cur && !/[\[\]\s:]/.test(v)) {
                            window.editorApi.renameFootnote(cur, v);
                        }
                    }
                });
                return {
                    dom: dom,
                    update: function(n) {
                        if (n.type !== node.type) return false;
                        node = n;
                        render();
                        return true;
                    },
                    selectNode: function() { dom.classList.add('ProseMirror-selectednode'); },
                    deselectNode: function() { dom.classList.remove('ProseMirror-selectednode'); }
                };
```

- [ ] **Step 1: 新增 `insertFootnote` 与 `renameFootnote`**

在 `editor.js` 的 `insertMermaid` 函数之后（约 886 行 `},` 之后）插入：

```javascript
    // 插入脚注（C++ 侧调用）：光标处插引用，文末容器追加空定义，焦点留正文
    insertFootnote: function() {
        var ed = this.editor;
        if (!ed) return;
        var schema = ed.state.schema;
        // 1) 扫描最大数字 id +1；无数字则从 1 起
        var maxNum = 0;
        ed.state.doc.descendants(function(node) {
            if (node.type.name === 'footnoteReference' || node.type.name === 'footnoteDef') {
                if (/^\d+$/.test(node.attrs.id)) {
                    var n = parseInt(node.attrs.id, 10);
                    if (n > maxNum) maxNum = n;
                }
            }
        });
        var newId = String(maxNum + 1);
        // 2) 光标处插入引用（insertContentAt 友好处理选区）
        ed.chain().focus().insertContentAt(
            ed.state.selection.from,
            [{ type: 'footnoteReference', attrs: { id: newId } }]
        ).run();
        // 3) 确保 footerContainer 存在并追加空定义
        ed.chain().command(function(ref) {
            var tr = ref.tr, state = ref.state, dispatch = ref.dispatch;
            var doc = state.doc;
            var last = doc.lastChild;
            var def = schema.nodes.footnoteDef.create({ id: newId });
            if (last && last.type.name === 'footnoteContainer') {
                // 容器内末尾（闭合标签前）插入 def
                tr.insert(doc.content.size - 1, def);
            } else {
                var container = schema.nodes.footnoteContainer.create(null, def);
                tr.insert(doc.content.size, container);
            }
            tr.scrollIntoView();
            dispatch(tr);
            return true;
        }).run();
    },

    // 改名（NodeView 双击触发）：遍历文档同步所有同 id 的 reference 与 def
    renameFootnote: function(fromId, toId) {
        var ed = this.editor;
        if (!ed) return;
        ed.chain().command(function(ref) {
            var tr = ref.tr, state = ref.state, dispatch = ref.dispatch;
            state.doc.descendants(function(node, pos) {
                if ((node.type.name === 'footnoteReference'
                     || node.type.name === 'footnoteDef')
                    && node.attrs.id === fromId) {
                    tr.setNodeMarkup(pos, null, { id: toId });
                }
            });
            dispatch(tr);
            return true;
        }).run();
    },
```
